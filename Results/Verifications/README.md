## 材料结构

- `<赛题>/README.md`：单题验证报告（结论、判据、数据、流程、环境）
- `<赛题>/raw/`：原始数据（日志、结果表、复现脚本、校验和）
- `panel/`：验证报告三卷（总览与裁定 / A210 / LX5000），含全局方法学与
  验证过程的完整记录

## 验证原则

1. 全部提交由组委会从冻结源码重新构建，选手提交的二进制不执行、不采信
2. 性能数据三轮取中位数，基线与选手验证轮数一致
3. 结论标注证据强度：经隔离实验证实者、经多方交叉对照者、单点观察者分别注明
4. 所引选手代码均为指向冻结版本的永久链接

复核中如需组委会提供本目录之外的原始数据（板上路径见各卷附录），请在 PR 下留言。
